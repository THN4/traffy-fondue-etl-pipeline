# traffy-fondue-etl-pipeline

An end-to-end automated Data Engineering pipeline designed to extract, clean, and model public municipal issue data from Traffy Fondue.

## Project Structure

```text
traffy-fondue-etl-pipeline/
├── notebooks/          # Jupyter notebooks for data exploration and prototyping
├── scripts/            # ETL pipeline scripts (extract, transform, load)
├── sql/                # SQL schema definitions, transformations, and data models
├── .env.example        # Environment variables template
├── .gitignore          # Files and directories to ignore in Git
├── docker-compose.yml  # Docker multi-container service setup
├── README.md           # Project documentation
└── requirements.txt    # Python package dependencies
```
